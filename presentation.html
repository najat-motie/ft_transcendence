01 / 08
Overview

What is ft_transcendence?

The Goal

Design and implement a modular full-stack web application demonstrating proficiency in modern web development, real-time communication, authentication systems, and scalable architecture.

The Concept

A real-time multiplayer Tic-Tac-Toe platform with multiple game modes, social features, an AI opponent, and a gamification system — all wrapped in a responsive, accessible UI.

The Approach

Feature-based modular development with each team member owning specific domains — backend auth, frontend architecture, game engine, and UI/infrastructure.

The Outcome

A production-ready platform containerized with Docker, served over HTTPS via Caddy, with real-time gameplay synchronization across separate devices.

02 / 08
Features

Key Features

  • JWT authentication with refresh token rotation
  • OAuth 2.0 login via 42 Intra
  • User profiles with avatars and stats
  • Friends system — send, accept, reject requests
  • Real-time multiplayer via WebSockets
  • Matchmaking — automatic player pairing
  • Private game rooms — create and join by code
  • AI opponent with balanced difficulty
  • Local 2-player mode on the same device
  • Game customization — themes, skins
  • Gamification — XP, wins, losses, win rate
  • Responsive and accessible UI across devices
